Envelope do Jorge
🚪💌 Você já recebeu um envelope do Jorge? Prepare-se para abrir o seu e descobrir o que está esperando por você!

https://jorge-pi.vercel.app/

->Descrição
Este é um projeto simples, feito inteiramente com HTML e CSS, onde o usuário pode interagir com um envelope animado. Ao abrir o envelope, um segredo é revelado, mas cuidado... o Jorge pode aparecer na sua casa se você não compartilhar!

->Funcionalidades:
Animações divertidas: O envelope tem animações ao passar o mouse e ao ser aberto.
Responsividade: O layout é adaptável para diferentes tamanhos de tela (funciona bem em dispositivos móveis!).
Texto interativo: Uma mensagem misteriosa é revelada após abrir o envelope.

->Como Usar
Abra o projeto em seu navegador.
Clique no envelope para ver o que o Jorge está escondendo.
Não se esqueça de compartilhar com três pessoas, ou o Jorge... bom, já sabe o que pode acontecer. 😜

CSS
